# Archived Character Rig Lab

These files document and preserve the first NPC rig-generation experiment.
They are intentionally outside Unity's `Assets` folder, so the old generators,
custom art-kit editor, and retired tests do not compile or add obsolete menu
commands.

The active system is now:

- `Assets/Prefabs/Characters/Core/Person.prefab`
- `Assets/Animations/Characters/Core/`
- `Assets/Art/Characters/Appearance/`
- `Assets/Scripts/Gameplay/Characters/`

Restore files from this archive only when deliberately revisiting the old rig
or 36-PNG segmentation workflow.
