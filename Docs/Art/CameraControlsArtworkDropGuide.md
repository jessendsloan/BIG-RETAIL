# Camera Controls Artwork Drop Guide

The four camera-view buttons live in the bottom-right view-control row,
immediately left of the wall visibility buttons.

Replace only these PNG files:

- `Assets/Art/UI/Camera/Icons/Camera_ViewNorth.png`
- `Assets/Art/UI/Camera/Icons/Camera_ViewEast.png`
- `Assets/Art/UI/Camera/Icons/Camera_ViewSouth.png`
- `Assets/Art/UI/Camera/Icons/Camera_ViewWest.png`

Keep the filenames and the existing `.meta` files unchanged. The placeholder
art is copied from existing construction icons. Unity imports all four camera
icons as single, full-rectangle sprites with transparency and no
mipmaps.
