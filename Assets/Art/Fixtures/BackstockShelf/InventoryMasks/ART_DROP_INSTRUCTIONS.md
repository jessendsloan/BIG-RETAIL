# Backstock shelf inventory masks

Export six transparent PNGs on the same 714 x 819 canvas as the matching
backstock rack sprite. Each image contains one opaque white shelf surface and
is otherwise transparent.

- Fixture_2x1_BackstockShelf01_RisingLeft_ShelfMask01_Top.png
- Fixture_2x1_BackstockShelf01_RisingLeft_ShelfMask02_Middle.png
- Fixture_2x1_BackstockShelf01_RisingLeft_ShelfMask03_Bottom.png
- Fixture_2x1_BackstockShelf01_RisingRight_ShelfMask01_Top.png
- Fixture_2x1_BackstockShelf01_RisingRight_ShelfMask02_Middle.png
- Fixture_2x1_BackstockShelf01_RisingRight_ShelfMask03_Bottom.png

After importing, match each mask's sprite pivot and pixels-per-unit to its
corresponding RisingLeft or RisingRight rack sprite, then run:

Big Retail > Fixtures > Install Initial Shelf Placement
