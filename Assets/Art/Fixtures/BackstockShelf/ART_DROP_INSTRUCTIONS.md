# Backstock Shelf Art Drop

Replace the temporary Half Shelf presentation by adding these three PNGs to
this folder, then run `Big Retail > Fixtures > Install Initial Shelf Placement`:

- `Fixture_2x1_BackstockShelf01_Icon.png`
- `Fixture_2x1_BackstockShelf01_RisingLeft.png`
- `Fixture_2x1_BackstockShelf01_RisingRight.png`

The fixture is a 2x1 employee storage rack accessible from either long side.
The two rising sprites are reused for the opposite camera views because the
empty rack is visually identical from both sides. Keep both canvases aligned
to the same footprint and pivot convention. No merchandising shelf masks are
needed because customers do not browse this fixture.
